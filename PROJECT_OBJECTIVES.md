1. Project Objective

The main objective of this project is to estimate the causal effect of product prices on sales using Double Machine Learning (DML).

The project aims to understand how changes in product prices influence customer purchasing behavior while considering other relevant factors.

2. Specific Objectives

- To understand the relationship between product prices and sales.
- To identify factors affecting sales, such as discounts, promotions, and customer demand.
- To collect, clean, and preprocess relevant pricing and sales data.
- To perform Exploratory Data Analysis (EDA) to identify patterns and trends.
- To apply Double Machine Learning to estimate the causal effect of price changes on sales.
- To evaluate the results and interpret the estimated effects.
- To generate useful insights for better pricing decisions.

 3. Expected Outcomes

- A cleaned and analyzed dataset.
- Exploratory data analysis and visualizations.
- A Double Machine Learning implementation for causal effect estimation.
- Evaluation of the estimated price effect and its uncertainty.
- Documentation of findings and potential business applications.

4. Conclusion

This project aims to use Data Science and Double Machine Learning to understand how pricing decisions affect sales and support data-driven business decisions.
